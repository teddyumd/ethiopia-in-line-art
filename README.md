# Ethiopia in Line Art — website

Landing page for *Ethiopia in Line Art: A Fun Coloring Journey* by Ethio Coloring Books.

Built with React, Vite, TypeScript, Tailwind CSS and shadcn/ui.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build     # output goes to dist/
npm run preview   # serve the built site locally
```

## Where things are

- `src/App.tsx` — the whole page (sections, text, links)
- `src/index.css` — global styles
- `public/images/` — book cover, sample pages, photos, logo
- `index.html` — page title, description and social-share tags

## Deployment

Hosted on Vercel. Every push to `main` deploys automatically.
